# Zakaria Al-Mokri — Portfolio

Personal portfolio website showcasing my work as a Software Engineer and IT Consultant. Built with React, TanStack Start, and Tailwind CSS.

## Tech Stack

- React + TanStack Start
- Tailwind CSS
- TypeScript
- Google Analytics 4 (with cookie consent)

## Development

You need [Bun](https://bun.sh) installed.

```sh
git clone https://github.com/zakaria-mokri/portfolio.git
cd portfolio
bun install
bun run dev
```
